# Glosario: español colombiano para recetas e ingredientes

Objetivo: que cualquier persona en Colombia reconozca el ingrediente por su nombre y lo encuentre
fácil en la plaza, la tienda o el supermercado. Se usa el nombre colombiano como `name` y, cuando el
ingrediente tiene otros nombres comunes en el mundo hispano, se agregan en `aliases` (para que la
búsqueda también funcione con esos nombres).

## Utensilios y verbos de cocina (para los pasos)

- `cocer` → **cocinar**; `hervir` se conserva.
- `freír en abundante aceite` → **fritar en abundante aceite** o **freír** (ambas se entienden; preferir "fritar" en frituras).
- `triturar / procesar con la batidora` → **licuar** (licuadora) o **procesar** (procesador de alimentos).
- `batir` se conserva (batidora eléctrica).
- `rebanada` → **tajada** (de pan, de plátano, de tomate); `lonja` → tajada.
- `cazo` / `cacerola` → **olla**; `paila` está bien en fritos.
- `sartén` se conserva; `plancha` se conserve.
- `fogón` / `estufa` para la fuente de calor: usar **estufa**.
- `nevera` / `refrigerador` / `heladera` → **nevera**.
- `papel de horno` / `papel manteca` → **papel parafinado (papel de hornear)**.
- `film transparente` → **papel vinipel (plástico transparente)**.
- `cuchara sopera` → **cucharada**; `cucharadita` se conserva.
- `patatas fritas` → **papas fritas**; `puré de patatas` → **puré de papa**.
- `tortilla` (mexicana) se conserva; `tortilla de patatas` → **tortilla de papa**.
- `bollo` de pan → **pan**; `bocadillo` (sándwich) → **sánduche**; en Colombia "bocadillo" es el dulce de guayaba.
- `sándwich` → **sánduche**.
- `ejotes`, `elotes`, `jitomates` en pasos → cambiar igual que en ingredientes.
- Tratamiento: mantener el imperativo de "tú" (Pica, Sofríe) como ya está.

## Regla para nombres de platos (títulos)

Se conserva el nombre tradicional del plato aunque use una palabra extranjera (Pad thai, Chiles rellenos,
Pastel de choclo, Tacos al pastor), pero la descripción y los ingredientes usan el vocabulario colombiano
("relleno de mazorca" en la descripción de un pastel de choclo, por ejemplo).
